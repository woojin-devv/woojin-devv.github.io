# DFS/BFS 알고리즘 연습.zip 🏠

DFS와 BFS는 단순히 탐색 코드를 외우는 것보다, **어떤 값을 상태로 관리하고 언제 방문 처리할지** 판단하는 연습이 중요하다.

프로그래머스 문제를 **기초 탐색 → 최단거리 → 백트래킹** 순서로 풀면서 탐색의 기본 구조부터 상태 설계와 최적해 탐색까지 연습해보자.

## 1단계. 연결된 영역 탐색하기

### 1. 무인도 여행

격자에서 상하좌우로 연결된 하나의 영역을 찾고, 영역을 구성하는 값의 합을 구하는 문제다.

이 문제는 DFS와 BFS 중 어느 방식으로도 풀 수 있다. 먼저 DFS로 구현한 뒤 BFS로 다시 풀어보면 재귀 호출과 큐를 이용한 탐색의 차이를 익히기 좋다.

#### 연습 포인트

- 2차원 격자의 행과 열 범위 확인하기
- 상하좌우로 이동할 방향 배열 만들기
- 방문한 위치를 중복 탐색하지 않도록 처리하기
- 하나의 영역을 모두 탐색하며 값 누적하기

#### 풀이 체크

- [ ] DFS로 풀이
- [ ] BFS로 다시 풀이
- [ ] 시간 복잡도 설명

### 2. 전력망을 둘로 나누기

전력망의 전선을 하나씩 끊어보면서 두 네트워크에 포함된 송전탑 수의 차이가 가장 작아지는 경우를 찾는 문제다.

간선을 제거한 뒤 한쪽 노드에서 DFS 또는 BFS를 실행해 연결된 노드 수를 세는 방식으로 접근할 수 있다.

#### 연습 포인트

- 간선 하나를 제외한 그래프 구성하기
- 연결된 노드 수 세기
- 한쪽 네트워크의 크기로 다른 쪽 크기 계산하기
- 모든 간선을 제거해보며 최솟값 갱신하기

---

## 2단계. 탐색으로 경우의 수 만들기

### 3. 소수 찾기

주어진 숫자 조각을 조합해 만들 수 있는 모든 수를 찾고, 그중 소수의 개수를 구하는 문제다.

라이브러리의 `permutations`에 의존하지 않고 직접 DFS를 구현하면 숫자 선택, 방문 처리, 원상 복구로 이어지는 백트래킹의 기본 흐름을 연습할 수 있다.

#### 연습 포인트

- 현재까지 선택한 숫자를 상태로 관리하기
- 숫자를 선택한 뒤 방문 처리하기
- 재귀 호출이 끝나면 방문 상태 복구하기
- 길이가 다른 순열 모두 생성하기
- `set`으로 중복된 숫자 제거하기

---

## 3단계. BFS로 최단거리 구하기

가중치가 없는 그래프에서 최소 이동 횟수를 요구한다면 BFS를 먼저 떠올린다. BFS는 시작점과 가까운 상태부터 탐색하므로, 어떤 상태를 처음 방문했을 때의 거리가 최단거리가 된다.

### 4. 가장 먼 노드

그래프를 인접 리스트로 만들고, 1번 노드에서 각 노드까지의 최단거리를 계산하는 문제다.

#### 연습 포인트

- 양방향 그래프의 인접 리스트 구성하기
- 거리 배열을 방문 여부와 함께 사용하기
- 최댓값과 같은 거리를 가진 노드 수 세기

### 5. 단어 변환

단어 하나를 탐색 상태로 보고, 한 번에 한 글자만 다른 단어로 이동하며 목표 단어까지의 최소 변환 횟수를 구하는 문제다.

#### 연습 포인트

- 두 단어에서 다른 문자의 개수 세기
- 다음에 이동할 수 있는 단어 판별하기
- 같은 단어를 다시 탐색하지 않도록 방문 처리하기
- 목표 단어가 목록에 없는 경우 처리하기

### 6. 리코쳇 로봇

한 칸씩 움직이는 일반적인 격자 탐색과 달리, 장애물이나 보드 끝을 만날 때까지 한 방향으로 미끄러져 이동하는 문제다.

#### 연습 포인트

- 현재 위치에서 네 방향의 정지 지점 계산하기
- 이동 경로가 아니라 **정지 지점**을 다음 상태로 사용하기
- 제자리에서 끝나는 이동 제외하기
- 도달할 수 없는 경우 처리하기

---

## 4단계. DFS와 백트래킹으로 최적해 찾기

백트래킹에서는 하나의 선택을 적용해 다음 상태로 이동한 뒤, 재귀 호출이 끝나면 선택 이전의 상태로 정확히 복구해야 한다.

### 7. 불량 사용자

각 불량 사용자 패턴에 일치하는 사용자 아이디를 선택하고, 가능한 제재 아이디 조합의 개수를 구하는 문제다.

#### 연습 포인트

- 패턴과 사용자 아이디가 일치하는지 판별하기
- 이미 선택한 사용자를 중복 선택하지 않기
- 순서가 달라도 같은 사용자 조합이면 하나로 처리하기
- 최종 선택 결과를 불변 형태로 만들어 중복 제거하기

### 8. 양궁대회

제한된 화살을 각 점수에 배분해 가장 큰 점수 차이를 만드는 경우를 찾는 문제다. 최적해가 여러 개일 때 적용되는 동점 조건까지 정확하게 처리해야 한다.

#### 연습 포인트

- 각 점수를 얻거나 포기하는 선택 설계하기
- 남은 화살 수를 재귀 상태로 관리하기
- 모든 화살을 사용한 경우만 결과 비교하기
- 최고 점수 차이 갱신하기
- 동점일 때 낮은 점수를 더 많이 맞힌 결과 선택하기

## 문제를 풀 때 확인할 것

- [ ] 탐색 상태를 한 문장으로 정의했는가?
- [ ] 방문 배열이 위치만 관리하는지, 추가 상태까지 관리해야 하는지 확인했는가?
- [ ] 방문 처리를 큐에 넣을 때 할지, 재귀에 진입할 때 할지 정했는가?
- [ ] DFS 호출이 끝난 뒤 복구해야 하는 상태를 확인했는가?
- [ ] 중복 경로와 중복 결과를 구분했는가?
- [ ] 최단거리가 필요한 문제에서 BFS를 사용했는가?
- [ ] 종료 조건과 도달할 수 없는 경우를 처리했는가?

## 시작 문제

첫 문제로는 **무인도 여행**을 추천한다.

DFS로 한 번, BFS로 한 번 풀어보면 같은 탐색을 재귀와 큐로 각각 구현하는 차이를 비교할 수 있다. 이후 전력망을 둘로 나누기에서 그래프 탐색을 연습하고, 소수 찾기에서는 `permutations` 없이 직접 DFS와 백트래킹을 구현해보자.
